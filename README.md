# Stock Exchange Analysis & Fraud Detection<br>

A Django-based stock exchange management system with trade matching and fraud detection modules.<br>

## Features<br>
- Stock trading simulation<br>
- Order matching engine<br>
- Fraud detection module<br>
- Django web interface<br>
- SQLite/MySQL database support<br>

## Technologies<br>
- Python<br>
- Django<br>
- SQLite/MySQL<br>
- HTML/CSS<br>
